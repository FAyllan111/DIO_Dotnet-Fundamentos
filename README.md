# Fundamentos do .NET

Este repositório reúne estudos e exemplos práticos desenvolvidos durante o módulo **Fundamentos do Bootcamp "Backend com .NET" da DIO**. O objetivo deste repositório é praticar os conceitos fundamentais de programação em C# e .NET, explorando conceitos básicos e estruturas que são a base para o desenvolvimento de software com a tecnologia .NET.

## Estrutura do Repositório
- **Exemplos de Estruturas Básicas de Programação**: Apresenta exemplos de uso de estruturas de controle como laços de repetição e condicionais.
- **Manipulação de Dados com C#**: Demonstra como manipular e trabalhar com diferentes tipos de dados no C#.
